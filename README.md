# CleanOK — независимый демосайт

Готовый статический сайт для демонстрации владельцу CleanOK, Челябинск. Проект **не является официальным сайтом компании**.

## Быстрый старт

Откройте `index.html` в современном браузере или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Никаких npm-зависимостей, установки и сборки нет.

## Размещение на Vercel

1. Создайте новый репозиторий GitHub `cleanok-website`.
2. Поместите в корень репозитория **содержимое** папки `CleanOK_site` (`index.html`, `styles.css`, `app.js`, `config.js`, `assets/`, `robots.txt`, `vercel.json`, README).
3. В Vercel нажмите **Add New → Project**, импортируйте репозиторий.
4. Framework preset: **Other**. Build command — **пусто**, Output directory — **пусто или `.`**.
5. Укажите название проекта `cleanok-demo`; адрес `cleanok-demo.vercel.app` возможен, только если свободен.
6. Опубликуйте и проверьте на телефоне. После первого импорта пуши в GitHub обновляют проект.

## Изменение данных

- `config.js`: телефон, внешние ссылки, опубликованные ценовые ориентиры.
- `index.html`: тексты, разметка разделов, навигация.
- `styles.css`: цвета, адаптивность, анимации.
- `app.js`: логика калькулятора, копирование, меню, появления блоков.
- `assets/*.svg`: оригинальные векторные изображения.
